# Enterprise AI Document Management & RAG Assistant

Built during my internship at PT Parama Data Unit to allow organizations to query internal policy, technical, and operational documentation with zero data exposure to external cloud providers.

## Key Architecture

- **Ingestion Pipeline:** Automatic document chunking with page number preservation for citation integrity.
- **Inference Server:** Local LLMs orchestrated via Ollama and exposed through an asynchronous FastAPI backend.
- **Client Frontend:** Next.js application supporting real-time streaming tokens and click-to-cite preview cards.
